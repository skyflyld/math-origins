乘法的魔法

—— 3×4 不只是三四十二

🎮 3×4 是在干什么？

3 × 4 = 12。你是记住了"三四十二"，还是真的理解了这个"×"符号在做什么？

乘法不是"背口诀"——乘法是加法的重复。3×4 = 3+3+3+3。把四步加法压缩成一步，这就是乘法。不是"规定"，是归纳。

🔲 乘法 = 矩形

3 × 4 = 3 行 4 列的矩形。乘法是"面积"的抽象。每个方块代表一个单位。

🧱 乘法三大定律

交换律（a×b=b×a）：3 行 4 列的矩形转 90° 就是 4 行 3 列——面积不变。结合律（(a×b)×c=a×(b×c)）：(2×3)×4 = 6×4 = 24。2×(3×4) = 2×12 = 24。两种路径，同一个结果。分配律（a×(b+c)=a×b+a×c）：3×(4+2) = 3×6 = 18。3×4+3×2 = 12+6 = 18。这些不是"背的规则"——把它们画成矩形，一目了然。

乘法速算：25 × 16 = ？不用竖式

✅ 400。25×16 = 25×4×4 = 100×4 = 400。或者 25×16 = (100÷4)×16 = 100×4 = 400。乘法不只是一个答案——它是一条可以有很多走法的路。

🚀 继续探索

乘法口诀的扩展——"两位数乘两位数"可以完全不用竖式。87×93 = (90−3)×(90+3) = 90²−3² = 8100−9 = 8091。平方差公式在暗处帮你省了巨大的计算量。数学里有很多这样的"暗门"——找到它们，计算就从苦役变成游戏。

乘法不是口诀。乘法是"重复加"的赞歌。
