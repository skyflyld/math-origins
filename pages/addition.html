第七关

加法的秘密

—— "加"就是"往后数"

🎮 加法到底是什么？

如果"加"这个操作从世界上消失——你不可以把两个数合在一起，不可以累计任何东西。你的生活会变成什么样？

加法是最早的数学运算。它比"数"本身还要古老——当人类第一次把两只手上的指头凑在一起时，加法就已经在无意识中被使用了。

➕ 加法 = "往后数"

3+2=5

从 3 开始，往后数两步：3→4→5。这就是加法的第一性定义——后继的重复。

🧱 加法从哪来？

从皮亚诺公理的第 2 条出发——"每个数都有一个下一个（后继）"——加法被定义为重复取后继的简写。

3 + 2 = S(S(3))。取 3 的后继（得 4），再取 4 的后继（得 5）。加法不是"加符号"——加法是"往前走"。

从这个定义可以推导出：交换律（a+b=b+a）、结合律（(a+b)+c=a+(b+c)）。这些不是"规定"——是从定义中必然推出来的结论。

🗺️ 加法在数学地图上的位置

加法是运算树的根：

➕ 加法 = 后继的重复
✖️ 乘法 = 加法的重复（3×2 = 3+3）
💥 乘方 = 乘法的重复（3² = 3×3）
依次往上，整个算术大厦建立在"加法=后继的重复"这个地基上。

✋ 自己动手！

不用"加"来解释加法——用"数"来解释

7 + 8 = ？不用竖式，用"数"的方式思考。

✅ 等于 15。从 7 开始往后数 8 步：7→8→9→10→11→12→13→14→15。或者用拆分法：7+8 = 7+3+5 = 10+5 = 15。加法的多种策略中，"凑十"是最自然的——因为我们的数制是十进制。

🚀 继续探索

加法看起来最简单，但它藏着一个"未解决问题"：哥德巴赫猜想——"任何大于 2 的偶数都可以写成两个素数之和"。4=2+2，6=3+3，8=3+5，10=3+7…这个猜想从 1742 年提出至今未被证明。即使最简单的东西，也可能藏着最难的谜。

从"往后数"到整个算术大厦——加法是数学的第一块砖。
