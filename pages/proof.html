第十九关

你怎么知道你对？

—— 量一万个三角形也不够

🎮 来玩个游戏

你量了一万个三角形的内角和，都是 180°。够了吗？不够。第一万零一个可能不是。数学不靠实验——靠证明。证明的意思是：不可能不对。

这是数学和其他一切科学最根本的区别。物理靠实验——实验一百次都对，第一百零一次可能推翻。数学靠证明——证明通过之后，永远对。不是因为"看起来对"——是逻辑堵死了所有其他可能。

🗡️ 三种证明武器

🔨 直接证明

从已知事实一步一步推出结论。三角形内角和：在顶点画一条和底边平行的线 → 利用"同位角"和"内错角" → 三个角拼成一个平角 = 180°。不需量、不需试、不需相信——从事实自己走出来。

💥 反证法

先假设结论是错的，然后推出一个和已知事实矛盾的结果。√2 是无理数的经典证明：假设 √2 = a/b（最简分数）→ a 是偶数 → b 也是偶数 → 和"最简分数"矛盾。所以 √2 不可能是分数。反证法的妙处在于：它不告诉你什么是对的——它告诉你"如果不是这样，世界会疯掉"。

🀰 数学归纳法

要证明"对所有自然数都成立"。先证明 n=1 成立。再证明：如果 n 成立，则 n+1 一定也成立。就像多米诺骨牌——推倒第一块，所有牌依次倒下。

§3 亲手试 —— 多米诺

🁫 数学归纳法的比喻

点击推倒，看 n→n+1→n+2→... 推理如何像多米诺一样传递。

✋ 试证一个定理

证明：三个连续自然数的和一定能被 3 整除

✅ n + (n+1) + (n+2) = 3n+3 = 3(n+1)。提取公因数 3 → 一定是 3 的倍数。用了"直接证明"——设第一个数为 n，代数运算，不依赖任何一个具体例子。证明完成。

🚀 无法证明的真相

有些数学命题——无法被证明，也无法被证伪。哥德尔不完备定理说：任何一个足够强大的数学系统里，都存在一些真命题，无法在系统内部被证明。这不是因为人类不够聪明——这是任何形式系统的内在局限。证明的边界，比数学的边界要窄——总有一些"真"在证明的射程之外。

证明是数学区别于所有其他科学的标志。不是因为对的多——是因为有办法说"不对"。
