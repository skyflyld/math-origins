第十一章

乘方

—— 乘法的乘法，数学里的爆炸

§1 钩子

一张纸厚 0.1 毫米。对折一次是 0.2 毫米，对折两次是 0.4 毫米——看起来很慢。但如果你能一直折下去，对折 42 次，它的厚度就能到达月球。你信吗？

这就是乘方的威力。2⁴² = 4,398,046,511,104 层纸 ≈ 44 万公里。月球距地球约 38 万公里。乘方不是"快"——乘方是"爆炸"。

📄 纸的厚度增长

厚度：0.1 mm（1层）

§2 第一性 —— 乘方 = 乘法的重复

2³ = 2×2×2。乘方是乘法的重复，就像乘法是加法的重复。三个运算排成一条线：加法→乘法→乘方。每一步都是"上一步的重复"。

但这还不是全部——乘方之上还有"迭代乘方"（2↑↑3 = 2^(2^2) = 2⁴ = 16）。运算可以一直往上叠，每次都比上一次"大得快得多"。这种"运算的无穷阶梯"启发了计算机科学中"计算复杂度"的概念。

§3 关系网

乘方的特殊成员：

² 平方——面积的基础
³ 立方——体积的基础
⁰ 任何数的 0 次方 = 1（为什么？因为 aⁿ÷aⁿ = aⁿ⁻ⁿ = a⁰ = 1）
⁻¹ 负指数 = 倒数（2⁻¹ = 1/2）

§4 亲手试

10⁰ 等于多少？

✅ 等于 1。10³÷10³ = 1000÷1000 = 1。但根据指数律：10³÷10³ = 10³⁻³ = 10⁰。所以 10⁰ 必须等于 1——不是"规定"，是从指数律推导出来的必然结论。任何非零数的 0 次方都等于 1。

§5 更深一层

乘方大到什么程度？围棋盘上第一格放 1 粒米，第二格 2 粒，第三格 4 粒...第 64 格需要 2⁶³ 粒米——大约是全世界几千年的大米总产量。这就是指数增长——开始时慢得不值一提，结束时大得无法想象。

乘方是数学里的"蝴蝶效应"——开始小到看不见，最后大到装不下。
